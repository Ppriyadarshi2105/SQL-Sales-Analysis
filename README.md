# 📊 E-commerce Sales Analysis (SQL Project)

## 🚀 Project Overview
This project involves designing an **E-commerce Sales Database** and analyzing business performance using **SQL queries**. The goal is to extract valuable insights, such as **total revenue, top-selling products, and best-performing customers**, to help businesses make data-driven decisions.

## 📌 Key Features
✅ **Database Schema Design** – Created structured tables for sales data.  
✅ **Data Cleaning & Transformation** – Processed raw sales data for accuracy.  
✅ **Advanced SQL Queries** – Used **JOINs, Aggregations, and Filters** to analyze trends.  
✅ **Business Intelligence Insights** – Extracted actionable insights on **revenue, customers, and product demand**.  

---

## 🛠 Tech Stack
- **Database:** MySQL
- **Query Language:** SQL  
- **Tools Used:**  MySQL Workbench

---

## 📂 Database Schema
The project contains the following **4 main tables**:

1️⃣ **Customers** – Stores customer details (Name, Email, Location).  
2️⃣ **Products** – Stores product details (Name, Category, Price).  
3️⃣ **Orders** – Contains customer purchase records.  
4️⃣ **OrderDetails** – Stores product-wise details for each order.
